# modelcatalog

Model registry and metadata for DSGo.

## Overview

- Canonical model IDs are `provider/model` (lowercased).
- Aliases map to canonical IDs via `RegisterAlias` and `Resolve`.
- The catalog is authoritative for `core.NewLM` (models must be registered).
- Default models are generated by `go generate` in `default_models.go`.

## Core Types

- `Model` (ID, aliases, pricing, limits, capabilities, modalities, metadata)
- `Pricing` (USD per 1M tokens)
- `Limits` (context/output tokens)
- `Capabilities` (tooling, structured output, reasoning, etc.)
- `Modalities` (input/output types)
- `Metadata` (name, family, release info)

## Common Operations

```go
model := modelcatalog.Model{
    ID: "openai/gpt-4o",
    Limits: modelcatalog.Limits{ContextTokens: 128000, OutputTokens: 16384},
    Modalities: modelcatalog.Modalities{Input: []string{"text"}, Output: []string{"text"}},
    Metadata: modelcatalog.Metadata{Name: "GPT-4o"},
}

if err := modelcatalog.RegisterModel(model); err != nil {
    return err
}

canonical, ok := modelcatalog.Resolve("gpt-4o")
_ = canonical
_ = ok
```

## Notes

- Registration is idempotent when the model definition is identical.
- `ListModels` and `ListModelsByProvider` return models sorted by ID.
- All registry operations are concurrency-safe.
